# Interview transcripts

`/call stop` writes each transcript here as `YYYY-MM-DD-<topic>-<first-name>.md`.

## Rules

- Each recording starts with the consent line. A transcript without the consent line is not used.
- The audio stays on the laptop (`~/agentic-marketing/audio/`). It is never committed.
- A person checks each transcript before an article uses it. The check sets `checked: true` in its front matter.
- Use the first name only. Remove phone numbers, addresses and employer names.
- **Git keeps history.** A file deleted later stays in the history. If a person asks for their data to be removed, open `/ask-tech` for a history rewrite.
