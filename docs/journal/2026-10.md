# Journal: 2026-10

## 2026-10-03 — T-02: the monorepo exists

- **What:** [#94](https://github.com/magentawood/roomsie/pull/94) makes the monorepo. `pnpm dev` starts the web app and the API. `pnpm test` starts a local Postgres 17 in Docker, makes a disposable database, and runs the tests. The API serves each route below `/v1`, and it generates its OpenAPI document from the Zod schemas of `packages/contract`.
- **Why:** ADR-0010 sets pnpm workspaces and Turborepo. ADR-0003 sets two apps that deploy independently. The grill of T-02 set the remaining choices: `tsx` for development, `tsup` for the build, postgres.js with prepared statements off for the Supabase pooler, and `pnpm db:up` as a separate command.
- **Design change:** the user said that the V3 prototype has no value at this time. The launch look comes from the Figma designs, which are not available at this time. PD12, PD5, the standards, the working docs, D-01 and T-23a changed. The prototype is in `docs/archive/`.
- **Dead ends:**
  - pnpm 12 does not run through Corepack, so the repo pins pnpm 11.28.2.
  - TypeScript 7 breaks typescript-eslint, so the repo uses TypeScript 6.0.
  - Turborepo writes an `AGENTS.md` when it finds an agent. `turbo.json` turns this off, because `CLAUDE.md` is the only entry point.
  - The plan generator kept the old checklist lines next to the new lines. The fix was to change the old lines in the notes first, then run the generator.
- **Next:** T-03 adds the CI gate. T-04 deploys the two apps. T-06 adds the first migrations.
